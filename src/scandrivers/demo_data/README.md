# Demo Data

This directory contains the minimal datasets used by the demonstration notebooks and loader tests.

## Layout

- `kt20/kt20_0467/117-289/record_scanner_10khz_*.csv`: KT-20 scan exports used for single-scan loading and directory aggregation in `kt20_scan_demo.ipynb`.
- `pxrf/Final/pXRF Readings (Trench1to6).xlsx`: pXRF workbook loaded by `pxrf_scan_demo.ipynb`.
- `pxrf/Final/pXRF Readings (Trench1to6).ndt`: Native pXRF fixture used to demonstrate resolution to its Excel sidecar.

Instrument photographs, alternate exports, temporary lock files, and generated analysis outputs are intentionally excluded.
